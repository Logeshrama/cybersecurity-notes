# Deloitte Australia Cyber Security Virtual Experience

**Date Completed:** October 2026

## Overview

Completed the Deloitte Australia Cyber Security Virtual Experience Programme through Forage.

The simulation involved investigating a suspected cyber security breach at a manufacturing company and analysing web activity logs to identify suspicious behaviour.

---

## Key Learning Outcomes

### Log Analysis

Learned how to:

- Read web activity logs
- Identify suspicious user behaviour
- Detect patterns in user requests
- Differentiate normal and abnormal activity

### Networking Concepts

Learned about:

- Internal networks
- Private IP addresses
- VPN access
- Web requests
- APIs

### Security Operations

Practised:

- Investigating a potential breach
- Examining evidence
- Identifying suspicious accounts
- Determining how access may have occurred
